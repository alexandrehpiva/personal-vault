# Personal Vault

Repositório privado para guardar ideias, anotações, projetos e referências pessoais.

## Estrutura

- **`ideias/`** — ideias soltas, insights e brainstorms, sem compromisso de virarem algo.
- **`projetos/`** — ideias mais desenvolvidas, com potencial de virar um projeto real.
- **`notas/`** — anotações gerais do dia a dia, aprendizados, reflexões.
- **`referencias/`** — links, artigos, livros e outras referências úteis para consulta futura.
- **`recursos/`** — templates, checklists e materiais de apoio reutilizáveis.

## Como usar

Cada pasta tem um `README.md` próprio explicando o que vai nela. Basta criar novos arquivos `.md` dentro da pasta correspondente, com nomes descritivos (ex: `ideias/2026-07-31-app-de-habitos.md`).

Sugestão de cabeçalho para cada nota nova:

```markdown
# Título da ideia/nota

**Data:** AAAA-MM-DD
**Tags:** #tag1 #tag2

Conteúdo...
```
